# Team Picker (Forge 1.20.1)

`/teampicker` 를 입력하면 접속 중인 플레이어의 머리가 격자로 뜹니다.
머리를 누르면 팀 선택 창이 열리고, **빨강팀 / 파랑팀 / 팀 해제** 중 하나를 누르면
그 플레이어가 바닐라 스코어보드 팀(`red`, `blue`)에 들어갑니다.

- 팀이 없으면 자동으로 만들어 줍니다 (빨강 = `red`, 파랑 = `blue`).
- 그래서 `/tp @a[team=red] 100 64 100` 같은 바닐라 명령어를 그대로 쓸 수 있습니다.
- OP(권한 레벨 2 이상)만 사용할 수 있고, 서버에서도 한 번 더 검사합니다.
- **서버와 클라이언트 양쪽에 모드를 설치**해야 합니다.
- 싱글플레이에서는 월드를 열 때 "치트 허용"이 켜져 있어야 명령어가 보입니다.

## 빌드 방법
1. Forge 1.20.1 (47.3.0) MDK를 받아 압축을 풉니다. (https://files.minecraftforge.net)
2. MDK 안의 `gradlew`, `gradlew.bat`, `gradle/` 폴더를 이 폴더로 복사합니다.
3. JDK 17이 설치된 상태에서 이 폴더에서 `./gradlew build` 를 실행합니다.
4. `build/libs/teampicker-1.0.0.jar` 를 서버와 클라이언트의 `mods` 폴더에 넣습니다.

## 파일 구조
- `PickerCommand` : `/teampicker` 명령어
- `network/` : 접속자 목록 전송 / 팀 지정 요청 패킷
- `client/` : 머리 목록 화면, 팀 선택 화면
